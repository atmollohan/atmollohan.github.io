- ☁️ **Cloud**: AWS, GCP, Azure
- 🐳 **Containers & Orchestration**: Kubernetes, Docker, Helm, OpenShift
- 🏗️ **Infrastructure as Code**: Pulumi, Terraform, OpenTofu
- 👁️ **Observability**: Grafana, Prometheus, VictoriaMetrics
- 🌐 **Networking**: Cloudflare, Tailscale, Nginx, Traefik, MQTT, Cilium
- 🧠 **AI**: Claude Code, Codex, OpenCode, Ollama, MCP
- 🤖 **ML**: TensorFlow, PyTorch, scikit-learn, MLflow, MLOps
- ⚙️ **Backend**: Go, Python, Node.js, TypeScript
- 🔄 **DevOps**: GitHub Actions, Jenkins, Balena, CI/CD

- 🔧 **Hardware**: Custom PCs, Home Lab, Game Hosting, Raspberry Pi, Device Repair
