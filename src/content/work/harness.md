## Role

Started as Software Engineer II, promoted to Senior Software Engineer I then II. Joined the security test orchestration team after Harness acquired ZeroNorth. Ran the day-to-day scrum and all ceremonies on top of being a full time developer: sprint planning, daily standups, retros, and backlog grooming. Worked across the full stack (frontend, backend, database, DevOps) and provided direct customer support. Received multiple Star Performer awards (2022, 2023, 2024).

## The Work

### Security Testing Orchestration (STO)

**Product Development:**
- Built Security Testing Orchestration (STO), Harness's first security product, built from the acquired ZeroNorth platform
- Grew STO from acquisition to $10M+ ARR in under 3 years
- Built large chunks of the core product across the full stack: React frontend, Go/Java backend, PostgreSQL database

**Cloud & Deployment:**
- Worked on GCP and Kubernetes for both SaaS and On-Prem deployments of Harness
- Migrated dozens of cloud runners from AWS to GCP
- Built automation and testing infrastructure around the runner fleet
- Maintained select accounts still running on AWS during the transition

**DevOps & Infrastructure:**
- Deployed and managed services on Kubernetes using Helm charts
- Built and maintained CI/CD pipelines for the STO product
- Managed infrastructure across GCP and AWS with Terraform

**Customer Support:**
- Provided direct support to customers integrating STO into their pipelines
- Troubleshot scanning, pipeline integration, and infrastructure issues
