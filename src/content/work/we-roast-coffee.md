## Role

Full Stack Engineer building the digital infrastructure for a specialty coffee roaster. Designed and implemented the technology stack that supported both wholesale operations and direct-to-consumer sales.

## The Work

### E-Commerce Platform

**Online Store:**
- Built custom Shopify theme with product customization options
- Implemented subscription system for recurring coffee orders
- Designed inventory management that syncs online and warehouse stock
- Created wholesale portal for cafe and restaurant ordering

**Payment & Fulfillment:**
- Integrated Stripe for payment processing with support for subscriptions
- Built automated fulfillment workflow that generates shipping labels
- Implemented tax calculation for multi-state compliance
- Created reporting dashboard for sales analytics

### Wholesale Operations

**Order Management:**
- Built internal tool for managing wholesale accounts and orders
- Implemented automated reorder notifications based on consumption patterns
- Designed delivery route optimization for local deliveries
- Created customer portal for order history and reorder functionality

## Impact

- Launched e-commerce platform that generated $100K+ in first year
- Built wholesale management system that reduced order processing time by 50%
- Implemented subscription system with 85% retention rate
- Designed inventory system that reduced stockouts by 40%

## Stack

Python, TypeScript, React, Node.js, PostgreSQL, Docker, AWS, Shopify, Stripe
