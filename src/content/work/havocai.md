## Role

Senior Platform Engineer and cloud platform owner. Own everything from infrastructure and deployments to security and compliance. If it runs in the cloud, it's my problem.

## The Work

### Cloud Infrastructure

**Kubernetes & Orchestration:**
- Designed and managed Kubernetes clusters for multi-tenant workloads
- Built Helm charts for deploying and scaling platform components
- Implemented auto-scaling for burst workloads with cost-optimized instance selection

**Infrastructure as Code:**
- Built Pulumi modules for repeatable infrastructure provisioning across AWS and GCP
- Implemented self-hosted hybrid infrastructure for cost-sensitive workloads
- Designed cross-account IAM patterns for secure operations

**CI/CD & GitOps:**
- Built GitHub Actions pipelines for infrastructure and application deployments
- Designed GitOps workflow with Flux and Helm chart versioning
- Implemented automated testing for infrastructure changes before production

### Security & Compliance

**Cloud Security:**
- Built container vulnerability scanning pipeline with Trivy
- Implemented CIS benchmark compliance for Kubernetes clusters
- Designed network policies for micro-segmentation between environments
- Remediated security findings and established compensating controls

**Compliance Framework:**
- Implemented DISA STIG compliance for container workloads
- Ran Kubebench assessments against Kubernetes clusters
- Created automated compliance scanning on every deployment
- Documented compensating controls for findings that couldn't be immediately remediated

### Day to Day

- Monitor and maintain production infrastructure across multiple environments
- Troubleshoot platform issues and respond to incidents
- Evaluate and integrate new tools and services as needs evolve
- Work with the team to plan infrastructure changes and scaling strategies

## Impact

- Scaled platform infrastructure to support growing workloads
- Reduced environment provisioning from hours to minutes
- Working towards CIS/DISA STIG compliance for production clusters
- Built security scanning pipeline that catches vulnerabilities before deployment
